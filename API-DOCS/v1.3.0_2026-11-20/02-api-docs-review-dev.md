> **Cách đọc bảng:** **Chỗ A / Chỗ B** là 2 chỗ nói khác nhau; **(A)** và **(B)** là 2 hướng sửa — xin dev xác nhận hướng nào đúng với hành vi server. Bảng ③ có cột **Câu hỏi cho WSSJ / dev**.

> **Severity:** `[MAJOR]` = khách dễ code sai hành vi / sai dữ liệu · `[MINOR]` = lệch nhỏ, dữ liệu mẫu, câu chữ.
